# 史序：地图叙事预览

基于用户提供的 PDF，将中国近代史时间轴做成可以播放、暂停和跳转的地图叙事。参考截图只提供地图与时间轴联动的方向；用户明确选择地图为主画面，并拒绝工作台式布局。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 `http://127.0.0.1:4173/`，默认从1840年鸦片战争开始。播放键或空格切换播放，左右方向键切换事件；底部进度条支持拖动、键盘 Home / End 与方向键。目录支持按类型、事件、年份、地点搜索。

右上角太阳/月亮按钮切换日夜模式。首次访问默认日间，手动选择会保存在当前浏览器；日间为白底、深蓝文字与朱红重点，夜间采用对应的深蓝底和浅珊瑚重点。地图、文字、控件和详情面板同步切换，播放进度保持不变。

`?event=e-1` 从1840年开始；`?event=e-27` 从南昌起义开始；`?event=e-29` 从秋收起义开始。阶段按钮跳到对应过程并暂停。暂停后可展开事件解读、同一时期的关联阅读、资料原文和考点回忆。

## 内容与出处

- `public/data/history.json`：100个内容节点，包含全部47条原时间轴条目；原表重复提到的会议与前面的会议专题合并。所有节点保留原文、PDF页码和简短解读。
- `public/sources/history.pdf`：用户提供的原PDF本地副本。链接中的页码为PDF页码，不是印刷页码。
- `scripts/extract-history.py`：从本机原PDF提取内容，需要 PyMuPDF。脚本明确保留原文，并对重庆谈判标题与正文日期不一致的情况记录说明。
- 地图与地点元数据来自 [阿里云 DataV 地理数据](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)及[地点索引](https://geo.datav.aliyun.com/areas_v3/bound/all.json)。`china.json` 为原始底图，`node scripts/prepare-geography.mjs` 可重新生成适配 d3-geo 的 `china-d3.json`。
- 地点坐标使用现代行政区中心进行示意。只有明确定位的节点显示地点标记，其他内容显示全国专题视角；省份高亮表示地点所在区域。
- “关联阅读”按同一时期选取，表示复习关联，不是自动断言历史因果关系。

## 动画与边界

全部100个内容节点均有逐条编排的过程动画，覆盖全部47条原时间轴条目。39个历史事件、30个会议、21个著作和10个土地政策节点，依内容采用地点转移、力量汇集、决策分支、观点交锋、理论实践循环、战略阶段、会师关系、三三制构成和土地权利转移等动画。地图镜头保持稳定，由内容的动作承担叙事。

`src/storyboards/catalog.js` 保存新增96段的逐条分镜、图中标签、动作类型和交叉依据；`src/ProcessGraphic.jsx` 实现相应动作，`src/storyboards/places.js` 使用本地DataV地点索引中的现代行政区中心。原有四段专门编排保存在 `src/stories.js` 与 `src/StoryLayer.jsx`。既有React、Vite、d3-geo与原生Web Animations API足够实现本轮需求，没有新增框架或动画依赖。

`src/StorySymbols.jsx` 提供 Phosphor 人物、议案、产业、组织等图符和中性的几何编队符号。人物由分散状态逐批集结，议案展开后归并到结果，部队编队沿示意方向推进、受挫停留并在文家市会合，土地关系区分田块、权利凭证、受让农户和受保护对象。三三制用人物与席位表示比例，战略阶段用双方编队与防线区分防御、相持和反攻。短距离集结和议案移动采用减速到位，地理行进维持匀速。全部动作仍由同一个可倒回的时钟驱动，没有增加装饰性的镜头拉伸。

秋收起义与三湾改编的补充依据来自[共产党员网](https://www.12371.cn/2021/01/09/VIDE1610159042141982.shtml)、[党史日志](https://www.12371.cn/special/ds/9/19/)、[中国军网](https://www.81.cn/js_208592/jdt_208593/16243563.html)、[中央纪委](https://m.ccdi.gov.cn/content/38/ab/18602.html)和[国防部](https://www.mod.gov.cn/gfbw/gfjy_index/js_214151/4921325.html)，也可在详情的资料原文页查看。虚线表示原定方向，实线表示后来的行动方向；均为示意线，不能当作精确行军路线。组织图中的连队是代表性节点，不表示实际编制数量。

分镜以保留的PDF资料为依据；需要结合其他原文条目的段落，在详情的“资料原文”中列出可打开的“分镜依据”。思想、方针和政策图表示内容关系，其位置不代表发生地点。罢工条目为不同事件比较，不表示时间顺序。三三制席位只表示比例；土地色块不表示面积、金额或实际分配比例。明确区分未实施方案、地价增值、减租减息、土地使用权与农民个人所有权。

所有过程动画从同一个播放器时钟采样，暂停、回拖、倍速同步作用于路线、部队标记和阶段说明。减少动态效果时直接显示当前阶段的结果。所有节点均已接入分镜，没有持续的镜头放大作为动画填充。

默认完整播放时间为12:00，保留全部100个节点。`storyboardEvents` 按复杂度、主线和关键转折分配时长，普通节点约5至7秒，关键节点约10至15秒。分镜仍使用原有内部时间；`storyTime` / `playbackTime` 在两套时间之间换算，让路线、阶段和跳转保持同步，不能只修改事件时长而遗漏动画时钟。缩时只改变默认停留时间，不删事件、阶段、动画或阶段说明。播放画面随阶段显示完整标题与说明，支持随时暂停细读；所有阶段也可从“详情 → 分段讲解”集中查看，事件摘要和PDF原文同样保留。

播放进度按叙事时长计算，不是按历史年份等比例计时。当前为本地交互预览：没有面向用户的视频导出功能或历史疆域、精确战役路线重建。原文中的资料口径保留在原文面板，简短解读用于阅读组织，不替代原始材料。当前对象与群体动画的正常速度实播见 `evidence/rich-motion-preview.mp4`。其他预览录屏保留用于对照之前版本。

## 验证

```sh
npm run build
npm run test:storyboards
```

完整部署指南（Vercel / GitHub Pages 零配置静态托管与可选自托管模板）见仓库根目录 [../README.md](../README.md) 与 [deploy/README.md](deploy/README.md)。

### 90 秒样片：道路与建军

打开 `http://127.0.0.1:4173/?lesson=road`。秋收起义 36 秒、三湾改编 30 秒、古田会议 24 秒；净讲解共 90 秒，含本地生成的普通话旁白、同步字幕与地图过程。20 秒在文家市会合处停表判断，答后再揭示史实；90 秒后恢复三事件顺序并匹配各自解决的问题，可按段回看。首次提交结果在本次会话中保留。

`完整内容` 保留三事件全部 12 阶段及资料原文；完整时间轴仍有 100 节点、720 秒。未添加学习成绩上传、外部语音服务或新依赖；即时复原不代表长期记忆效果已验证。

验证：`npm run test:lesson`、`npm run test:storyboards`、`npm run build`。旁白重建：`node scripts/render-lesson-audio.mjs`（macOS Tingting、ffmpeg），输出 `public/audio/road-90.m4a`，90.000 秒。

### 完整时间轴配音与字幕

完整时间轴现支持 100 个节点的普通话合成配音及同步字幕，默认开启，底部“配音”“字幕”可分别切换并保存偏好。点击播放后出声，暂停、进度拖动、上一幕/下一幕、倍速、详情阅读及切换到后台均与音轨同步。配音概括讲述过程，全部分段说明和资料原文仍然保留；总长保持 12 分钟。

完整时间轴采用用户确认试听的 GPT-SoVITS v2ProPlus 音色。播放器标为“AI配音”，不是参考作者本人讲述或认可。164 段讲稿保持不变；字幕由同一批生成音频逐段计时，不使用识别转写替换原稿。100 节点、303 阶段和资料原文保留，编码音轨精确为 720 秒。独立的 90 秒样片沿用原音轨。

`public/audio/timeline-zh.json` 指向带内容哈希的 M4A 与 WebVTT。所有声音在本机生成，不上传参考音频到外部语音接口；载入失败可继续看字幕和地图，并通过配音按钮重试。旧音轨保留，切换前清单备份在 `../output/voice-timeline/backup/`。

本地复建需要 `../output/voice-tools/gpt-env/bin/python`、GPT-SoVITS 模型与 `../output/voice-reference/` 中已确认的参考材料。`npm run audio:timeline` 仅生成暂存版本，不立即切换播放器；运行本地检查后才可发布：

```sh
../output/voice-tools/gpt-env/bin/python scripts/audit-cloned-voice.py --work ../output/voice-timeline
# 如有短句误报，可运行 audit-cloned-context.py / audit-cloned-mandarin.py 复查；真实错读须重生成。
# 每次重生成后，重新构建暂存音轨并更新检查。
npm run audio:publish
npm run test:narration
```

两处短句采用完整上下文生成后按语音边界切分，`scripts/apply-context-voice-repairs.py` 保留原始上下文和切分证据。检查清单绑定原稿、原始片段和暂存音轨的哈希；未解决的语音疑点会阻止本地切换。自动识别仅用于排查漏读、重复和错读，不代表真人逐句听审或音色相似度验证。`npm run audio:timeline:system` 保留 macOS Tingting 备用生成方式。
